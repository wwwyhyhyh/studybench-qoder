# 图与最小生成树

## 图的存储：邻接矩阵与邻接表

邻接矩阵用 $n\times n$ 方阵存边：无向图的矩阵对称，第 $i$ 行元素之和就是顶点 $i$ 的度；带权图存边权，无边用特殊值表示。优点是判断两点邻接 $O(1)$、求度数快，适合稠密图；缺点是空间 $O(n^2)$，稀疏图浪费严重。邻接表给每个顶点挂一条边链表，空间 $O(n+e)$，遍历某点的所有邻边只需顺着链走，适合稀疏图；代价是判断两点是否相邻要扫描整条链。选型口诀：稠密用矩阵，稀疏用表。做遍历与最短路时先想清楚存储方式，因为访问邻居的顺序不同会影响同层访问次序；若题目要求唯一的输出序列，通常默认邻接表按编号从小到大建链。有向图要区分入度与出度，逆邻接表专门用来快速求入度，拓扑排序删边时两套表配合最方便。

## BFS 与 DFS 的适用差异

BFS 借助队列按层扩散，天然给出无权图的单源最短路径：第一次到达某顶点时的层数就是最短边数。DFS 借助栈或递归一条路走到黑再回溯，适合求连通分量、拓扑排序、割点与桥。两者时间复杂度相同：邻接表 $O(n+e)$，邻接矩阵 $O(n^2)$。注意 DFS 不是最短路：第一个被访问到的路径不一定边数最少。实现细节：BFS 要在入队时立刻标记已访问而不是出队时，否则同一结点会被重复入队导致队列膨胀；DFS 递归深度过大时改用显式栈防爆栈。无向图判环可在 DFS 中遇到"已访问且非双亲"的结点判定；有向图判环则要用三色标记法区分"在当前递归栈中"与"已完成"。带权图的最短路必须换用 Dijkstra 或 Bellman-Ford，BFS 只对无权图给出最短路。

## 最短路：Dijkstra 与 Floyd

Dijkstra 解决单源最短路，要求边权非负。流程：每次从未确定的顶点中取距离最小者加入已确定集合，然后松弛它的所有出边；用优先队列实现时复杂度 $O((n+e)\log n)$。贪心正确性依赖非负权：一旦有负边，已确定的距离可能被后续路径推翻，负权图应改用 Bellman-Ford，复杂度 $O(ne)$ 且能检测负环。Floyd 求所有点对最短路，三重循环 $O(n^3)$，核心转移是 $d[i][j]=\min(d[i][j],\,d[i][k]+d[k][j])$，注意中间点 $k$ 必须放在最外层循环。选型：稠密图、点数几百以内时 Floyd 代码最短；单源且边权非负选 Dijkstra。常见错误两个：Dijkstra 忘了跳过已确定顶点导致重复松弛；Floyd 把 $k$ 写进内层循环，转移顺序错误后结果看似合理实则错误，极难肉眼发现。

## Kruskal：并查集与边排序

Kruskal 从森林出发构造最小生成树：先把所有边按权值从小到大排序，依次考察每条边，若两端点不在同一连通块就选入并用并查集合并，选够 $n-1$ 条边即停。正确性由切割性质保证：若一条边是横跨某个割的最小边，它一定存在于某棵最小生成树中。时间瓶颈在排序，$O(e\log e)$，稀疏图上表现好。并查集务必配路径压缩与按秩合并，操作近乎常数；写法上 find 用递归或迭代均可，合并时把矮树挂到高树下。常考问答：为什么要先按边权排序？因为贪心策略要求每次都优先尝试当前最便宜的合法边，不排序就退化为随意拼树，无法保证权值和最小。判断两点是否连通不要重新跑遍历，直接查并查集的根是否相同。图不连通时 Kruskal 自然得到最小生成森林，题目若要求输出无解要先判连通。

## Prim：稠密图上的选择

Prim 从一个起点开始生长生成树：维护每个顶点到当前树的最短距离数组 lowcost，每轮选出距离最小且不在树中的顶点加入，再用它的出边更新邻居的 lowcost，重复 $n-1$ 次。朴素实现两重循环 $O(n^2)$，与边数无关，因此稠密图（$e$ 接近 $n^2$）首选 Prim；配二叉堆可降到 $O(e\log n)$，稀疏图更优。与 Kruskal 的对比是高频简答题：Prim 维护的是点到树的距离，适合稠密图；Kruskal 维护边权的全局排序，适合稀疏图。手算题技巧：把已入树的顶点涂色，每轮只在所有"涂色到未涂色"的边上选最短，选完立刻更新，避免遗漏。常见错误：选中新顶点后忘记用它出边更新 lowcost，或更新时忘记取最小值导致后面选错点。两个算法得到的生成树权值和一定相同，但树的形态可能不同，判断题常在此设陷阱。

## 拓扑排序与关键路径

拓扑排序只对有向无环图有定义：反复输出入度为 0 的顶点并删除其出边，用队列实现 $O(n+e)$；若中途没有可输出的顶点，说明图中存在环。同一个 DAG 的拓扑序可能不唯一，题目若要求字典序最小，把队列换成小根堆即可。AOV 网排课程先修关系、AOE 网算工程工期都建立在这个算法上。关键路径求 AOE 网中最长路径：按拓扑序正向递推事件最早发生时间 $ve$，按逆拓扑序反向递推最迟发生时间 $vl$，活动 $(u,v)$ 的最早开始为 $ve(u)$、最迟开始为 $vl(v)-w(u,v)$，两者相等的活动就是关键活动。关键路径决定总工期：压缩工期必须压缩关键活动，但关键活动压缩过度可能使关键路径转移，需要重新计算。常见错误：逆推前忘记把所有 $vl$ 初始化为汇点的 $ve$，或者把最早最迟两组量的方向弄反。

## 二分图判定与匹配入门

二分图是顶点可分成两组、所有边都横跨两组的图。判定方法：从每个未染色的顶点出发做 BFS 或 DFS 二染色，相邻顶点颜色必须相反，出现冲突即不是二分图。判定定理好记：图是二分图当且仅当不含奇数长度的环。二分图最大匹配的经典解法是匈牙利算法：为左部点寻找增广路，若目标右部点已被占用，就尝试让原有匹配换一个对象，找到增广路则匹配数加一，复杂度 $O(ne)$。应用极广：任务分配、课程与教室的对应、设备与工位的匹配都能建模为二分图匹配。做题第一步永远是确认模型：题目问"最多能配成多少对"且关系只存在于两类对象之间时，先想二分图再写算法。常见错误：图不连通时只从单点染色，漏判了另一个连通分量；以及忘记每次尝试增广前清空访问标记数组。

## 图论题常见错误清单

本章错误高度集中，考前按清单过一遍。一是把无向图当有向图存：无向图每条边要按两条有向边各存一次，边数翻倍，数组开小会越界。二是邻接表建表顺序影响遍历输出，题目要求唯一序列时必须按题面规定的顺序插入边。三是 Dijkstra 遇到负权会静默出错，写之前先检查边权符号。四是并查集只合并不压缩或没按秩合并，大数据集上超时。五是拓扑排序只减了出边对应点的入度却没同步维护队列，导致漏点或死循环。六是最小生成树只对连通图成立：图不连通时应输出森林或报告无解，Kruskal 天然得到森林而 Prim 只覆盖起点所在连通块。七是手算关键路径时正向与逆向递推方向颠倒，得出负的最迟时间。建议每次刷题后对照本清单复盘，把错因归类到这七条里，两周后错题率会明显下降。
